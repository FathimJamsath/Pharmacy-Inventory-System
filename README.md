# 💊 Pharmacy Inventory System

A desktop-based Pharmacy Inventory Management System developed using Java Swing, MySQL, and JDBC. The system helps pharmacies manage medicines, suppliers, stock levels, and billing operations efficiently.

---

## 🚀 Features

- Medicine Management
  - Add medicines
  - Update medicine details
  - Delete medicines
  - Search medicines

- Supplier Management
  - Add suppliers
  - Update supplier information
  - Delete suppliers

- Stock Management
  - Track inventory levels
  - Update stock quantities
  - Monitor medicine availability

- Billing System
  - Generate bills
  - Calculate totals
  - Record sales transactions

---

## 🛠 Technologies Used

- Java
- Java Swing
- MySQL
- JDBC
- IntelliJ IDEA
- XAMPP
